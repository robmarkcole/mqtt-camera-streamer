# Public demonstration images

- `plate-sample.png`: [FastALPR sample](https://github.com/ankandrew/fast-alpr/blob/master/assets/test_image.png), ankandrew, distributed with its MIT-licensed repository. Retained license: `LICENSE.fast-alpr`. The known sample plate is 5AU5341.
- `rome-parking.jpg`: [Parking in Rome](https://commons.wikimedia.org/wiki/File:Parking.in.rome.arp.jpg), Adrian Pingstone (Arpingstone), June 2007. Released into the public domain by the author. Resized to 1280px wide; no detections were drawn into the input.

`sources.json` records file hashes and provenance. Generated demo outputs and screenshots add actual model predictions and are labelled as stock-image demonstrations, not live camera observations. Repeating a still image exercises track/OCR confirmation, not movement or real arrival/departure detection.
